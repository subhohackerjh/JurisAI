## ❓ Common Questions

### Q: Which demo account should I use?
**A:** Use `mohan@example.com` (Citizen) to see the most features.

### Q: Password isn't working?
**A:** Password for all accounts is exactly: `password`

### Q: Page isn't loading?
**A:** Check that `pnpm dev` is running and port 3000 is open.

### Q: Mobile menu not working?
**A:** Make sure you're testing on actual mobile device or browser in mobile view (F12 → Toggle Device Toolbar).

### Q: Can I permanently save data?
**A:** No, all data resets when you refresh. This is a demo app.
